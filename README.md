# Проект "Store"

## Проект "Store" - это онлайн магазин, который позволяет смотреть категории и товары. Добавлена функция связанная с JSON файлами, а также 2 новых класса с чётким раздением и множественное наследование присутствуют.

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/username/project-x.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```

## Использование:

1. Откройте приложение в вашем веб-браузере.
2. Нажмите на категорию которая интересует.
3. Выбирете продукт с его основными характеристиками и ценой.
